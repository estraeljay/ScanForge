# Sample: synthetic box (SYNTHETIC TEST DATA)

Generated by `scripts/make_fixtures.sh` from an analytic 120 × 80 × 60 mm box on a table, rendered as noisy depth
and reconstructed with the same core pipeline the phone uses. It is **not** a real scan and says so in its metadata
(`capture.source = "synthetic"`, tag `synthetic`).

* `synthetic-box.sf3d` — ScanForge package (verified format; import in Blender via *File › Import › ScanForge 3D*).
* `synthetic-box.glb` — the same model as glTF (meters, +Y up).

Expected in Blender: object "Synthetic Box" ≈ 121.5 × 60.6 × 75.5 mm (X × Y × Z) with the base on Z = 0;
phone-side measurement "Height above support surface" ≈ 80.4 mm (see docs/validation/synthetic-accuracy.md).
